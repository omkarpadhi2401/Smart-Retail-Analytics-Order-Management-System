# AI-Powered Business Finance and Inventory Analysis System

**Student:** Omkar Padhi · **Roll No:** 24101C0003 · **Class:** INFT-C

A web-based business intelligence platform for small and medium businesses. It combines finance
management, inventory management and sales analytics with forecasting, anomaly detection, a
Financial Health Score and AI-generated business recommendations.

## How to run

1. Install Python 3.10 or newer.
2. Double-click `run.bat` (Windows), **or** run:
   ```
   pip install -r requirements.txt
   python app.py
   ```
3. Open http://127.0.0.1:5000 and sign in with **admin@shop.com / admin123** (staff dashboard).
4. Customer panel: http://127.0.0.1:5000/shop — sign in with **omkar.padhi@gmail.com / omkar123** or register a new customer.

### Database

* **MySQL (preferred):** start MySQL (for example from XAMPP). The app connects as `root` with an empty
  password, creates the database `business_finance_db` and loads the demo data automatically.
  You can also import `database.sql` yourself (phpMyAdmin > Import, or `mysql -u root -p < database.sql`).
  For a different login, copy `.env.example` to `.env` and edit it.
* **No MySQL running?** The app falls back to a local SQLite file (`demo_data.db`) with the same
  data, so it can always be demonstrated. The top bar shows which database is in use.

### Using MySQL Workbench

1. Open MySQL Workbench and click your **Local instance MySQL** connection (enter your root password).
2. Open the `.env` file in this folder with Notepad and type the same password after `DB_PASSWORD=`. Save.
3. Run `run.bat`. The top bar of the app should now show **MySQL**.
4. In Workbench, click the refresh icon in the **Schemas** panel, open `business_finance_db` > Tables,
   right-click a table > **Select Rows** to see the data.

Manual import instead: Workbench > Server > Data Import > *Import from Self-Contained File* > choose
`database.sql` > Start Import.

## How the AI / analytics features work (`analytics.py`)

* **Demand forecasting** – monthly unit sales per product are de-seasonalised with a store-wide seasonal
  index, a linear trend is fitted with scikit-learn `LinearRegression`, projected 3 months ahead and
  re-seasonalised. Recommended stock = next month's forecast + safety stock (1.65 × forecast error).
  Accuracy is back-tested on the last 3 months.
* **Expense anomaly detection** – robust Z-score (median and MAD) of each expense against similar past
  expenses, plus month-over-month spike detection per category.
* **Financial Health Score** – Profitability, Expense Control, Cash Flow, Revenue Growth and Inventory
  Efficiency, 20 points each, from fixed formulas (no randomness).
* **AI recommendations** – a rule engine over forecasts, stock levels, expense spikes, cost-vs-revenue
  growth, cash flow and margin changes. Every recommendation quotes the numbers that triggered it.

## Demo data (`seed.py`)

12 months (Oct 2025 – Sep 2026): 24 products, 20 customers, 6 staff, 4,828 sales orders (9,448 order
lines) and 253 expenses in 8 categories. It includes festive seasonality, growing and declining products,
low-stock / out-of-stock / overstocked items and four planted unusual expenses.
`python seed.py` regenerates `database.sql`.
